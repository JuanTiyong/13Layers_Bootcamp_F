# 13Layers Academy — DevOps Bootcamp

Bienvenue dans le dépôt officiel du parcours DevOps **13Layers Academy**. Chaque formation est autonome et se trouve dans `formations/FXX-...`.

## Formations

| Code | Formation | Supports | Travaux des étudiants |
|---|---|---|---|
| F01 | Git & GitHub | [Ouvrir F01](formations/F01-Git-GitHub/README.md) | [Devoirs F01](formations/F01-Git-GitHub/devoirs/) |
| F02 | Linux & ligne de commande | [Ouvrir F02](formations/F02-Linux/README.md) | À rendre dans son fork, sous `formations/F02-Linux/devoirs/prenom-nom/` |
| F03, F04... | À venir | Voir [roadmap](ROADMAP.md) | Même convention |

**Commencez par [CONTRIBUTING.md](CONTRIBUTING.md).**

## Règle pour tous les futurs modules

1. Forkez ce dépôt, clonez **votre fork** localement.
2. **Déplacez-vous dans le dossier du module** avant de créer votre branche. Exemple F02 : `cd formations/F02-Linux`, puis `git switch -c Bootcamp_F02__prenom_nom`.
3. Suivez le cours demandé, réalisez les exercices et complétez votre dossier `devoirs/prenom-nom/` **dans le module**, pas à la racine.
4. Poussez votre branche vers **votre fork** et ouvrez une Pull Request pour correction vers le dépôt officiel. Le formateur peut valider et fermer la PR **sans fusion dans main**.

Le dépôt principal publie les supports officiels ; les devoirs historiques déjà fusionnés en F01 ont été rangés dans le dossier F01. Les prochaines remises vivent dans les forks jusqu'à leur évaluation.
