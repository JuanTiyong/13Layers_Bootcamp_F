QUESTION 1

Git est un gestionnaire de version: c'est un programme qui permet aux développeurs d'accéder à l'historique de conception d'un projet (ses différentes versions)

Avantages:
-comparer plusieurs versions d'un même projet grâce a son historique de conception.
-permettre à une équipe de travailler individuellement sur un projet puis de fusionner directement leurs travaux.

QUESTION 2

GitHub est un logiciel qui permet a plusieurs utilisateurs de travailler sur un projet commun sans toute fois que le travail de l'un affecte et détruise celui de l'autre.

Git est un gestionnaire de versions tandis que GitHub héberge les dépots en ligne

QUESTION 3

Un repository est la zone ou sont situés les différentes versions d'un projet sur l'ordinateur de l'utilisateur

un dépôt local est l'ébauche d'un projet enregistré directement sur le pc de l'ordinateur tans dis qu'un dépôt distant est la version en ligne accessible à tous ou à un groupe de personne en particulier.

QUESTION 4


git add: permet de choisir sélectionner les modifications à sauvegarder
exemple: git add styles.css

git commit permet de permet d'enregistrer les modifications dans un dépôt local

git push permet d'envoyer des repository sur un dépôt distant

QUESTION 5

une branche est une partie du projet qui sera associé a d'autre branches pour constituer le projet.
il faut travailler sur une branche dédié car la branche principal est réservé à la partie du projet lue et approuvée par les autres et il faudrait que la partie dédié soit suffisamment approuvée pour intégré la branche principale dans le cas contraire on risquerait de reprendre le projet depuis le début en cas d'erreur.

QUESTION 6

Un commit est l'enregistrement des modification dans l'historique d'un dépôt. permet de conserver les traces de modifications apportées au projet
il est important pour comprendre facilement l'historique de modifications

QUESTION 7

git fetch permet de récupérer les nouveautés du dépôt distant sans les intégré au dépôt local actuel contrairement à git pull qui intègre directement ces modifications au dépôt local.

QUESTION 8

UNE PULL REQUEST est une commande qui permet d'intégrer les modifications d'une branche à une autre. elle permet d'examiner le code et de proposer des corrections.

QUESTION 9

UN conflit git c'est lorsque Git ne peut pas fusionner automatiquement des modifications.
pour y remédier il faut rendre les fichiers à fusionner compatibles

QUESTION 10

Cloner le dépôt : git clone lien_du_depot
Entrer dans le dossier : cd nom-du-depot
Créer et rejoindre une branche : git branch ma-branche
git checkout ma-branche
Créer et modifier le fichier presentation.md.
Préparer les modifications : git add presentation.md
Enregistrer les modifications : git commit -m "Ajout de la présentation"
Envoyer la branche sur GitHub : git push -u origin ma-branche
Sur GitHub, créer une Pull Request pour proposer l'intégration des modifications dans la branche cible.
