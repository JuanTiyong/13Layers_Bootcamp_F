# Devoirs F02 — Espace de remise

**Les étudiants ne travaillent pas directement dans le dépôt officiel.** Ce dossier sert de repère pour retrouver l'emplacement de remise dans votre **fork**.

Dans votre fork, créez le sous-dossier `prenom-nom/` et ajoutez : `REPONSES_F02.md`, `RAPPORT_TP.md`, `FICHE_SUIVI.md`, `scripts/` et `preuves/`.

Référez-vous aux [consignes de remise](../03_CONSIGNES_REMISE.md). Créez **la branche `Bootcamp_F02__prenom_nom` après être entré dans le dossier F02 et avant toute modification**.

Les Pull Requests de devoir seront évaluées mais **ne sont pas destinées à être fusionnées dans `main`**.
